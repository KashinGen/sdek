## API

Данный API предоставляет эндпоинты для работы с данными о доставках. Реализована функциональность получения списка доставок с фильтрацией и пагинацией, а также получения детальной информации о конкретной доставке.

## Маршруты

### 1. **GET** `/api/deliveries`

#### Описание
Возвращает список доставок с поддержкой фильтрации по статусу и пагинации.

#### Параметры запроса (Query Parameters)
- `status` (необязательно): Фильтрует доставки по текущему статусу. Например, `delivered` или `in-transit`.
- `page` (необязательно): Номер страницы для пагинации (начинается с 1). По умолчанию равен `1`.

#### Пример запроса

```http
GET /api/deliveries?status=delivered&page=2
```

#### Пример ответа (JSON)
```json
{
  "items": [
    {
      "uuid": "abc123",
      "name": "Delivery 1",
      "statuses": [
        { "code": "in-transit", "timestamp": "2023-10-01T10:00:00Z" },
        { "code": "delivered", "timestamp": "2023-10-02T15:30:00Z" }
      ]
    },
    {
      "uuid": "def456",
      "name": "Delivery 2",
      "statuses": [
        { "code": "in-transit", "timestamp": "2023-10-01T12:00:00Z" }
      ]
    }
  ],
  "pagination": {
    "currentPage": 2,
    "totalPages": 5
  },
  "headers": {
    "Cache-Control": "no-store, max-age=100"
  }
}
```

#### Ответы
- **200 OK**: Успешный запрос, возвращает список доставок.
- **500 Internal Server Error**: Ошибка загрузки данных о доставках.

---

### 2. **GET** `/api/deliveries/[uuid]`

#### Описание
Возвращает детальную информацию о доставке по её `uuid`.

#### Параметры маршрута (Route Parameters)
- `uuid` (обязательно): Уникальный идентификатор доставки.

#### Пример запроса

```http
GET /api/deliveries/abc123
```

#### Пример ответа (JSON)
```json
{
  "uuid": "abc123",
  "name": "Delivery 1",
  "statuses": [
    { "code": "in-transit", "timestamp": "2023-10-01T10:00:00Z" },
    { "code": "delivered", "timestamp": "2023-10-02T15:30:00Z" }
  ]
}
```

#### Ответы
- **200 OK**: Успешный запрос, возвращает данные доставки.
- **404 Not Found**: Доставка с указанным `uuid` не найдена.
- **500 Internal Server Error**: Ошибка загрузки данных доставки.

---

## Локальное хранилище данных

Данные о доставках загружаются из файла `generated_data.json`, который хранится в директории `public`. Файл должен соответствовать следующему формату:

```json
{
  "items": [
    {
      "uuid": "abc123",
      "name": "Delivery 1",
      "statuses": [
        { "code": "in-transit", "timestamp": "2023-10-01T10:00:00Z" },
        { "code": "delivered", "timestamp": "2023-10-02T15:30:00Z" }
      ]
      ...other data
    }
  ]
}
```

---

## Общие ошибки и их решения

- **500 Internal Server Error**: Убедитесь, что файл `generated_data.json` существует и имеет правильный формат.
- **404 Not Found**: Проверьте, что запрашиваемый `uuid` существует в данных.
